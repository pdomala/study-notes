# AWS Certified Generative AI Developer – Professional (AIP-C01) · Revision Notes

Topic-organised revision notes for the **AWS Certified Generative AI Developer – Professional (AIP-C01)** exam. Each section packs the key points, detailed notes, scenario "exam triggers" and click-to-reveal flashcards for one topic. The notes cover Amazon Bedrock, RAG, agents, AgentCore, guardrails, security, governance, cost/latency and evaluation.

> **Unofficial.** These are independent study notes and are not affiliated with or endorsed by Amazon Web Services. AWS generative AI services change quickly, so check the official AWS documentation and exam guide for the latest details.

## How to use these notes

1. **Read the Key points** at the top of a section for the quick summary.
2. **Go through the Notes** for the detail behind each subtopic.
3. **Skim the Exam triggers.** Each one pairs a scenario cue with the service or feature it points to.
4. **Drill the Flashcards.** Answer each question out loud before you expand it.
5. **Speed-drill [16 · Exam Triggers](16-exam-triggers.md).** Aim for cue → answer in under 5 seconds; this is what the scenario questions test.
6. **Do a service sweep** with [15 · AWS Services Flashcards](15-aws-services-flashcards.md).
